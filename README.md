# Evaluación Parcial N° 2 - Geolocalización y API REST

## Descripción
Proyecto desarrollado en Python para el consumo y optimización de la API REST de geolocalización y cálculo de rutas con GraphHopper, traduciendo indicaciones al español y formateando la salida de datos.

## Requisitos
- Python 3.x
- Biblioteca `requests` (`pip install requests`)
- Servidor local GraphHopper en el puerto 8082 o API Key válida

## Comando de ejecución
```bash
python rutas_graphhopper.py
